### Overview

Design System Preview was an internal tool created to help mobile teams better understand how design system components translated from Figma into implementation.

The goal was to create a shared reference point where designers and engineers could review components, themes, and typography together — improving consistency and making implementation decisions easier to discuss.

Due to the internal nature of the project, I can only share selected parts of the work.

### The Challenge

Design systems often live across different environments.

Designers work primarily in Figma, while engineers work with code and implementation details. This can create gaps where components may look similar but behave differently across products.

The challenge was finding a way to make implementation more visible and create a shared language between design and engineering teams.

---

### The Approach

I designed a live preview environment that connected our design system concepts with their Android implementation.

Rather than treating design and code as separate sources of truth, the tool allowed teams to explore the relationship between the two and identify differences earlier in the process.

The focus was on:

- Improving visibility between design and implementation
- Creating shared terminology across disciplines
- Helping designers better understand technical constraints
- Supporting more consistent product experiences

### Working Closer With Engineering

A key part of the project was creating a closer relationship between design and engineering.

By working more directly with Android implementation concepts and terminology, I was able to better understand technical constraints while helping designers become more familiar with how the system was built.

The goal was not for designers to become engineers, but to create enough shared understanding that both teams could make better decisions together.

---

### Outcome

The project helped identify and improve gaps on both sides of the design system.

It highlighted:

- Differences between design and implementation
- Areas where components needed clearer definitions
- Opportunities to improve collaboration around the design system

More importantly, it helped start conversations around how design and engineering could align more effectively.

---

### Reflection

This project reinforced that a design system is more than a collection of components — it is a shared language between teams.

By making implementation visible, Design System Preview helped move conversations from comparing screenshots towards understanding how products are built.
