This is a personal project born out of a curiosity to learn how design systems are actually created in code. Having used a few of the popular options on the web right now, I've worked across various design system projects in my work at Opera. I was also a bit sick of writing my own components multiple times and using other systems without fully understanding how they worked. So it was a good chance to kill two birds with one stone.

The project is currently in progress, with the base component created alongside the first version of the project website, which is live at [lakrits.paullarkin.info](https://lakrits.paullarkin.info).
