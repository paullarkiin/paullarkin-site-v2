### Background

During my internship, I wanted a personal project that I could build in vases so that I could improve, learn, and practice the app creation cycle from design to deployment.

While researching security-related projects, I found that a number of published apps were had confusing layouts that, were visual unappealing, didn't enforce any kind of secure password functionality and didn't offer pin generation.

So for my own app, I took on these points and set about including them in the design and development, using card-based elements for a minimal clean look.

### Sketches

While sketching out the screen, I made an effort to simplify the process for the user to generate while making available the option to generate either a password or pin. I considered different flows to do this with and with bottom navigation and ended up splitting the feature list across two versions.

The design and implementation had a positive outcome with the app now live. I have received positive feedback from senior developers in my team, but more importantly, positive feedback from user reviews.

![User Reviews](/img/playstore/reviews.jpeg)

### Next Steps

- Reflect on user feedback and make adjustments to version one

- Review version two designs and iterate on them to see if I can improve the user experience and feature list

- Start building version two

### Reflection

I gained a lot of understanding and functional knowledge of the app end-to-end process from design to shipping the app. This not only made me feel more confident in my ability, but gave me an insight into how designs get translated and implemented in code.
